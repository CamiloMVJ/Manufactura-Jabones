# FRIDAYS · Identidad visual

La marca utiliza una F con corte diagonal, rojo vino y oro antiguo. El archivo PNG tiene fondo transparente y se comparte entre navegación, acceso y favicon.

| Función | Color | Aplicación |
| --- | --- | --- |
| Rojo vino | `#7C2336` | Acciones principales, enlaces y selección |
| Vino profundo | `#642135` | Barra superior |
| Oro antiguo | `#B8914B` | Marca, líneas, indicadores y acentos |
| Oro oscuro | `#78591F` | Texto dorado legible |
| Marfil | `#F7F5F1` | Fondo de trabajo |
| Tinta | `#2C2427` | Texto principal |
| Blanco cálido | `#FFFEFC` | Superficies y controles |

Los estados de éxito, advertencia, información y error conservan colores semánticos diferenciados. El dorado claro no se utiliza como texto de lectura sobre blanco.

Los estilos de marca se concentran en `static/css/brand.css`, después de los componentes estructurales de `styles.css`. La paleta y el logo se aplican a todos los módulos sin cambiar los flujos de trabajo.

Logo: `static/brand/fridays-f-burgundy-gold-v1.png`.

Origen: herramienta integrada de generación de imágenes; edición de la primera F azul para conservar su geometría y sustituir su tratamiento de color. Prompt exacto: `static/brand/fridays-f-burgundy-gold-v1.prompt.txt`.
